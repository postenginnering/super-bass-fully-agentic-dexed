# Super Bass Fully Agentic Dexed 1.0.1 R7

R7 在自动记忆与每预设连续上下文版本上新增 macOS 原生 AUv2。

macOS Universal ZIP 与 PKG 包含：

- Standalone 应用；
- VST3 插件；
- AU `Super Bass Fully Agentic Dexed.component`。

PKG 会把 AU 安装到 `/Library/Audio/Plug-Ins/Components`。发布流水线分别构建 x86_64 与 arm64，合并 Universal 二进制后完成签名、公证、stapling、双架构检查和 `auval -v aumu AgDx Agnt` 验证。

Windows R7 继续提供 x64 Standalone 与 VST3。AU 仅适用于 macOS。

本地预检已确认 Windows Release 构建、9/9 CTest 和 pluginval strictness 8 通过。macOS 原生构建与 AU 验证以 R7 Release runner 上传的日志为准。
